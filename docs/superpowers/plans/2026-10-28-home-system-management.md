# 首页与系统管理实施

依据已批准主计划第4/14/15节及最新权限、直角风格、功能优先要求。

1. 新增角色首页：创作者仅本部门稿件/检查统计；审核员与管理员查看校内业务、数据/模型/任务统计。展示六项真实功能入口、近14日趋势、状态分布和近期稿件/任务，周期刷新实际数据库，不造数据。规划中的外部事实核验仅显示规划状态。
2. 管理员系统管理：账号搜索/角色/启停筛选和分页，创建账号、编辑姓名/角色/部门、启停；部门搜索/分页、创建/改名/启停；复用现有口令编码器和operation_log。不回传口令/哈希，不硬删除关联历史。当前管理员不能停用/降级自己，最后管理员保护；创作者须有有效部门。修改权限下一请求生效。
3. 系统运行页：实际队列与历史状态、搜索分页、链接到现有任务页；在线检测/OCR服务状态、Java/MySQL连通；操作日志筛选分页。只读诊断不启动/停止模型，不更改全局配置。后台样本保持运行。
4. 前端复用Element Plus/ECharts和现有外壳，增加首页与系统管理导航；首页作为登录落点。所有卡片/按钮/对话框直角，简洁文案、加载/错误/空态、键盘焦点，图表无导出。
5. 必要检查：前后端构建及一次真实三角色/管理CRUD/权限变更/自保护/日志/首页范围检查；不跑繁复回归。部署须先核验后台任务并保护检查点，再按原参数续接。记录实际结果及阶段GitHub提交。
