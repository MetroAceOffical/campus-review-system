# 图片几何与OCR回退接入（阶段18）

依据技术设计第6/7节和已批准功能优先计划；后台正式生成、数据和轮数保持。

1. 新image-v2决策配置复用DINO特征空间，提供旧image-v1按configId重放。DINO Top20与SHA/pHash候选合并，SIFT/RANSAC输出整图/局部对应、内点、双侧区域与覆盖。相似分数不替代几何支持；缺源文件、预算不足分别记录状态。
2. 旧索引不重写；从同代input-manifest.json读取路径前核对其规范内容摘要与索引inputManifestHash，按文件/修订身份绑定，执行时仍校验受控路径及文件SHA。新索引沿用可追溯输入清单。
3. OCR服务同时接受旧ocr-v1和新ocr-v2，后者复用现有960→1600/分块、坐标映射和去重；服务适配/归一化代码与软件进入新配置身份。Java按所选配置读取及核对服务可用列表，缓存按新身份隔离；旧固定配置和结果保留。
4. 报告补图片双侧区域及整图/局部标签、OCR实际处理策略/覆盖；直角风格、文字简洁，不新增图表导出或免责声明。只补必要交互，不做前端改版。
5. 现有隔离环境及OCR环境均已有OpenCV，不新增依赖。CPU实测实际图片请求与OCR HTTP，进行少量核心契约检查、前后端构建。OCR仅在空闲时按登记身份重启；GPU检测保持停止。记录真正完成的接入及尚未开展的GPU/独立效果，阶段更新GitHub。
