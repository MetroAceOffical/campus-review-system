# 多数据集组合（阶段15）

依据已批准主计划5.1、5.3节及用户继续实施要求。

1. 选择2—10个同类型、清洗完成的不同数据集版本，明确目标部门与名称，创建独立组合数据集。原版本保留；角色沿用审核员/管理员。
2. 组合任务进入现有CPU数据队列。固定来源ID、版本及SHA，实际读取校验后的文件；行ID按来源数据集区分，保留原来源/事件/分区和原始溯源。来源/事件编号采用原值保守归组，不能将组合视作新增独立事件。
3. 复用现有清洗、精确去重与标签/分区/分组冲突隔离，产出新CLEAN版本、逐行来源映射、源清单及逐源处理统计。含糊冲突不擅自改标签或分区，不影响在跑正式数据。
4. 组合输入以小型sources.json不可变清单登记为RAW来源；只能下载清单，不能将其当普通CSV重新清洗。完整处理后新CLEAN可继续样本准备、训练、预测及参考入库。
5. 前端增加来源版本选择、队列/实际进度和组合来源报告，复用原直角样式。必要检查、真实已有清洗材料只读组合、构建后记录进度并上传GitHub；不部署重启或新装环境。
