# 新闻原稿自动准备训练样本

沿用批准的完整计划第7节。优先功能，必要构建及真实闭环检查；不新增环境，不覆盖旧语料/旧生成队列，不重做全面回归。

1. NEWS已分组版本 → 合并为有原文范围的段落窗口 → 跨分区重复片段隔离。
2. 复用现有Qwen2.5-3B权重、事实保持提示、数字/名称/长度/复制检查；命中相同原文的合格历史输出可只读复用，不把旧小样本安排作为前置条件。所有原稿默认处理，用户可以明确选择数量用于联调。
3. 同分区内检索候选，复用negative_basis内容差异依据规则；无依据候选保持无标签，不用随机换稿或低相似度制造负例。
4. SQLite逐次保存生成输出与检查；取消/重启保留状态，继续时创建新run并核对原稿/参数身份，旧结果不覆盖。
5. 输出PAIRS样本版本、类别/来源/隔离/耗时统计、原文与改写预览、实际事件及SHA；类别不足显示缺口，合格结果直接进入现有六模型训练，后台单并发。
6. 旧“模型实验”撤出导航和路由，旧地址跳转模型管理；旧源码、固定实验数据/报告及只读接口保留，管理员首页转训练页。

原正式校园不少于20,000对应样本、两类各至少20%、BGE不少于1,000查询组及完整评价等约束保持。本模块新增的是用户选择NEWS版本的样本准备能力；工程联调和自动构造标签不写成正式校园效果验收。
