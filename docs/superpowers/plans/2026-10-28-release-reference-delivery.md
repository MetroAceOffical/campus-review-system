# 模型发布、回退与批量参考入库

继续已批准主计划。复用原环境、直角组件及后台训练队列，不降低语料规模。

1. 发布按校级默认/部门及场景分开，版本不可变，活动指针用预期版本比较切换，历史记录可回退。正文审核配置复用已支持的两套冻结配置，消费端在创建新检测快照时锁定发布ID/配置；已锁定报告不变。工作台六类句对模型属于句对预测接口，须独立评价与产物核验，发布后由正式预测入口解析活动指针。不能把句对分类权重直接当作BGE/M3检索配置。
2. 句对发布验证复用既有CPU加载/预测，核对模型与评价SHA、原始阈值/分数口径、固定样本重算；记录评价而不伪造效果达标。正文配置登记核对冻结文件/权重/特征空间，切换需匹配当前索引。校园BGE/M3未来产出兼容审核配置后再登记，不把当前PAWS句对效果当新闻审核效果。
3. 清洗NEWS版本可申请入校内共享参考库；审核员申请、管理员批准，管理员可直接明确发起。批量任务持久化逐行结果、重复/失败/成功数量和来源，支持中断续接；不逐篇重建。整批准备后CPU构建一次不可变索引，旧图片只复用经哈希校验的已有特征，缺特征则保留旧库并等待，不抢生成GPU。新索引完整落盘且CAS切换才报告生效。
4. 数据中心/参考库提供批量入口与进度；模型发布页提供场景、归属、核验/切换/回退及生产预测。正式入库/发布只管理员可切换；创作者不开放数据管理。
5. 必要构建及一次真实发布/回退/旧快照、批量入库/重复/来源/索引切换与权限核验；其余综合回归后置。部署前保护全量生成检查点、原参数立即续接。记录实际进度和GitHub提交。

实施结果：2026-10-28已部署8080。3个发布版本完成CPU核验，正文配置发布→回退→恢复默认与CAS冲突拒绝通过，部门2的已发布LR完成真实CPU句对预测；在用模型禁止归档，独立评价按模型查询而非截断最近任务。旧审核pipeline快照逐项哈希未变。

实际217篇本校训练域新闻经审核员申请、管理员批准整批入库：137新作品、80重复、0隔离，CPU一次切换索引17→18；原57张图片特征逐项保留，新来源在实际TF-IDF索引Top10检出。未取开发/最终域补入这批训练新闻。初始化时修正工作器读取事务代理字段的空值问题；恢复全量生成时642条已处理记录逐项保持，最终run为69ce0f98-93cb-4c63-aedd-840c32b33f34。

交付边界：正文发布仅现有两套兼容配置，工作台模型正式消费场景是句对预测；新增校园BGE/M3审核配置仍待实际训练/校准/接入。本阶段分类阈值沿用模型族既有定义（SVM为0，其余0.5），未声称新校园阈值校准、效果目标或最终评价完成。完整运行时代码/环境冻结、交付任务纳入系统汇总及综合视觉/键盘验收按后续阶段继续。
