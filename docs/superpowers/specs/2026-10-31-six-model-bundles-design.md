# 正式数据集与六模型成组训练、发布设计

用户已确认实施。正式入口按数据版本组织 LR、SVM、RF、CNN、BiLSTM、BERT 六个模型，同一组共享样本准备和训练/验证/测试划分。小样本调试记录保留在历史区域，不删除文件、旧报告或版本。

## 数据

复用已下载的 PAWS-X 及校园新闻、已有合格改写和有依据负例，整理公开句对、本校新闻、其他院校新闻和综合训练四个正式集合。先核实可用数量、标签来源、保护划分及重复关系，再导入；原稿篇数与句对数分别统计。无标签新闻不能冒充训练句对。综合集只合并原训练域，保留来源和划分，不能将开发/最终留出集混回训练。旧正式样本准备仍暂停，不擅自恢复长任务。

## 训练与续训

新建任务固定六种模型，保留各模型参数配置；按同一准备版本依次训练与独立评价，展示 0—6 完成状态。失败仅重试当前子任务，成功结果不重复训练。组续训对 CNN/BiLSTM/BERT 使用各自父模型权重，LR/SVM/RF 重新拟合。旧单模型结果可查看和预测，但不作为新的六模型组冒充发布。

## 发布与审核

发布以完整六模型组为单位，核验六个实际模型、数据版本、独立评价和适配器。推荐主模型依据共同验证材料上的召回、误报及 F1 选择，发布时固定；不比较未经校准的原始分数来挑最大值。审核复用相同候选和对齐材料，分别计算六种模型的真实结果，默认展示主模型全文证据，可切换查看其余模型。历史报告绑定原配置，不被新发布覆盖。发布和回退均保存整组身份。

图片检索、OCR、语法检查、图文一致性仍使用已有专项模型。六模型组指文字复用检测，不将其余检测项目伪装为六个文字分类器的能力。

## 界面与权限

延续直角蓝灰风格、固定工作流程导航和紧凑布局。数据和模型默认展示正式集合/训练组，可进入历史记录；分页支持跳页及自定义单页数量。不增加图表导出、免责声明、重复跳转按钮。仅管理员训练和发布，审核员可上传/清洗/参考入库，普通成员无训练权限。

## 完成依据

以实际导入清单、共同划分校验、真实六模型任务、组发布核验、六模型实际全文检测与网页联调为依据。下载或整理完成不能写成训练或效果验收完成。每阶段报告实际进度、剩余工作及预计耗时，并同步现有 GitHub 开发分支。
