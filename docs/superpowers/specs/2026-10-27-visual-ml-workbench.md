# 南京传媒学院部门数据与模型工作台设计摘要

**状态：用户2026-10-28批准开始实施。** 主文档为[期末重构完整计划](../../期末重构完整计划-2026-10-27.md)，截止2026-11-01 12:00 Asia/Shanghai。以新执行计划与实际验证记录推进；新增环境/依赖或冲突仍先请示。

## 范围与身份

以南京传媒学院为例，以学生会工作部门和校新闻中心检验导入、清洗、训练、评估与使用。中国药科大学只是举例，不扩展为多学校租户系统，不新增institution权限实体。已下载其他高校语料保留真实来源，用于辅助训练/评价；材料来源学校与本系统部门归属分开。

成员可处理本部门数据/任务/实验模型，管理员管理校内部门与正式发布，审核员保持正式报告权限。模型发布按部门/场景记录，没有专用模型时使用已核验校级默认；共享参考有明确范围。

## 页面和共用稿件

首页功能工作台、数据中心、训练、模型管理、评估、实验预测和系统管理分别有清楚入口。

内容审核、语法检查和图文一致性进入同一稿件工作台：父编辑器始终显示，三个结果面板读取同一manuscriptId/revision/contentHash。切换保留正文、图片fileId、图注、来源和未保存修改，不按完整子路由销毁父编辑器。修改或采用建议后产生新内容身份，旧结果保留并等待重检；迟到结果不得覆盖新稿。成员草稿预检与审核员正式只读版本分别鉴权。

未来功能显示准确状态，不用占位图冒充结果。前端移除免责声明式长文，使用简短操作、状态、指标和必要错误反馈；详细方法放文档。

## 数据可选与批量导入

- 可选：内置与用户数据都登记到数据中心；选择具体ID/版本，或建立有来源/比例/去重记录的组合版本。所选数据实际进入计算，不只切换标题。
- 导入：CSV/JSONL整批上传，可含几百/几千篇文稿；模板、字段映射、预览和错误明细支持一次批量处理，不逐篇参考录入。
- 原始新闻：id/title/text/department/url/published_at/source_institution。正文必需，部门权限由服务端决定；外校名称仅为材料来源。
- 标签句对：sentence1/sentence2/label，附source_id/group_id/label_origin；标签0/1。
- 原始新闻先质量/清洗、原作/事件分组划分，再由系统准备事实保持改写正例与有依据负例；控制样本单列并限占比。既有标签数据可跳过生成。不要求用户手工制作全部句对。
- 原始、清洗、样本和划分各有版本；数据集、参考库和模型库是不同用途。训练不自动把原稿当已发布新闻。
- 拟定50MiB/100000行，支持UTF-8/BOM、多行CSV与中文字段；超限明确拒绝，不静默截断。

## 运行与可视化

六类文字模型可选并可设置参数，调参创建新运行。质量、清洗、样本、训练和评价为持久任务；Python实际事件由Java保存并经SSE推送，断线/刷新按序号恢复，轮询作兼容回退。

展示完整率/重复/异常、长度/来源/年份、清洗前后、类别/分区、实际step/epoch/Loss/验证指标/资源、混淆矩阵/ROC/PR/误例和运行比较。传统模型不补造epoch曲线；适用图支持缩放、hover、图例和PNG/CSV/JSON导出。

自由实验和正式最终评价分开：正式最终集不能训练/调参，配置冻结后才运行，查看记录保留。已有正式训练与评价规模不缩小。

## 后端与复现

沿用Vue/Element Plus/ECharts、Spring Boot/MySQL和现有Python环境。新增ml_dataset/version、ml_run/event、ml_model/release及与既有organization关联，增量迁移、独立runtime/workbench目录。固定计算入口，验证数据/参数/工件SHA、保留历史；资源冲突/新依赖先请示。

语法和图文功能的候选、数据、指标单位和验收以主计划12—13节为准；图片/OCR上传训练不纳入。
