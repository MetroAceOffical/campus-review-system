## 目录约定

```text
docs/
  README.md、当前进度.md、需求范围.md、技术设计.md
  运行手册.md、实验结果.md、验收与后续工作.md
  reports/       三份正式课程 DOC
  templates/     两份原始课程实验模板
  assets/        学校毕业设计时间节点图
  delivery/      已有 ZIP、文件清单、核对结果和校验值
  midterm/       原始 JSON、PNG 验证证据，路径保持兼容
```

根目录 README 与 app 内 README 只保留导航。后续更新直接修改对应主文档，不再新增按日期命名的交接、方案初稿或逐阶段进度副本。只有新的实验批次、输入、配置或验证事实需要独立证据文件。

文档以“当前事实、已确认需求、待讨论建议、历史证据”区分状态。续写时同步修正受影响的旧结论，避免新旧表述冲突；确需新增文档时，及时更新本入口和相关主文档，不形成第二套进度与方案。冻结的原始研究资产及历史验收证据按原有约定保留，不为同步状态改写历史数值。

`validation/` 中的实验协议、数据说明、模型卡和历史结果属于原始研究资产；其中14份 Markdown 已被580项冻结清单引用，保持原位和原字节。它们不是当前项目进度入口。`runtime/` 内的报告编写副本、运行报告、备份及私有配置仍是本机工作材料，不作为第二套正式文档。
